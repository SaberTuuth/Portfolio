Pathfinding Simulator

About Path Finder Simulation

Pathfinder Simulator is a 2D real-time visualization tool that demonstrates how different pathfinding algorithms operate, allowing users to observe AI decision-making as it happens. The project is designed to help developers and learners understand how pathfinding is used in video games by visually breaking down each step of the search process. In addition, it serves as a practical debugging tool for game developers to test map layouts and identify high-traffic (hot) and low-traffic (cold) zones without the need to launch a full game editor. The simulator supports multiple tile shapes, including square, hexagonal, and triangular grids.

Introduction

This project is a real-time pathfinding visualization tool built to strengthen my understanding of algorithms, data structures, and grid-based navigation systems commonly used in software and game development. The application supports square, hexagonal, and triangular tile maps, with all nodes and neighbor relationships initialized dynamically based on grid type. Users can customize the grid size, tile colors, background, and pathfinding speed, allowing algorithms to be observed and compared in real time. I implemented Breadth-First Search (BFS) and Depth-First Search (DFS) with step-by-step visualization, along with tools to inspect node connections and neighbor relationships. The project was built entirely in Java and JavaFX to intentionally deepen my Java skills while applying them to a practical, visual problem. This project demonstrates my ability to design clean rendering systems, manage application state, and build interactive tools that make complex algorithms easier to understand. It also serves as a foundation for adding more advanced algorithms such as A*, Dijkstra’s, and weighted pathfinding.
